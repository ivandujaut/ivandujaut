## Context

This is the site you're navigating. I built it from scratch aiming to have
a personal portfolio that serves as both a technical showcase and a
learning journal.

## Technical decisions

I chose Next.js for App Router and server components. MDX for content
because it allows me to write posts as files in the repo without needing
a CMS. next-intl for bilingual ES/EN support.
