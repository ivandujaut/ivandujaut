## Contexto

Este es el sitio que estás navegando. Lo armé desde cero con el objetivo
de tener un portfolio personal que sirva como showcase técnico y a la vez
como bitácora de aprendizaje.

<Callout type="info" title="En progreso">
  Este proyecto está activo. Voy sumando features semana a semana.
</Callout>

## Decisiones técnicas

Elegí Next.js por App Router y server components. MDX para contenido porque
me permite escribir posts como archivos en el repo sin necesidad de un CMS.
next-intl para soporte bilingüe ES/EN.

### Por qué Velite y no otra cosa

Evalué Contentlayer pero está deprecated. Velite lo reemplaza con mejor
DX, tipos automáticos via Zod, y soporte nativo para MDX en Tailwind v4.
