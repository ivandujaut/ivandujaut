## Contexto

Empezamos por la columna principal: tipografía serif, secciones numeradas y
texto justificado con hyphenation<Sidenote>Las sidenotes flotan al margen
derecho en pantallas `xl:` y se colapsan a una nota inline expandible en
mobile. Misma numeración correlativa que las footnotes.</Sidenote>. La
primera letra de esta sección lleva drop cap automática gracias a la regla
`.paper .prose-content > h2:first-of-type + p::first-letter`.

El texto convive con citas externas<Cite to="tufte2001" n={1} /> y notas al
pie<Footnote>Las footnotes son inline-expandibles vía `<details>`-like state.
Marker `²` superscript sin brackets, para distinguirlas de los cites
`[1]`.</Footnote>, dos categorías que mantenemos visualmente separadas.

<Callout type="insight" title="Cuando agregar una sidenote">
  Si la nota agrega contexto que se entiende sin volver al cuerpo, va al margen. Si requiere
  desplegarse, va como footnote inline.
</Callout>

## Pasos para autorear un caso nuevo

1. Creá `content/projects/{locale}/{slug}/index.mdx` y co-locá tus assets en
   esa misma carpeta (`./hero.png`, `./demo.mp4`, `./figma-*.png`).
2. Abrí con `<Abstract>`, después una `<Figure fullBleed>` como hero. Una
   composición arriba, una frase corta debajo, sin más.
3. Estructurá en secciones numeradas: Contexto, Decisiones, Resultados,
   Próximos pasos. Una visual cada 300-400 palabras.
4. Cerrá con `<References>` si citaste fuentes externas. No es obligatorio
   cuando no hay citas externas.

## Patrones que no se renderizan en este sandbox

Tres componentes necesitan assets externos o permisos de embed que el sandbox
no tiene: video MP4, embed de demo en vivo, y Figma. Quedan acá como
referencia de sintaxis.

### `<FigmaEmbed>` con archivo compartido

```mdx
<FigmaEmbed
  url="https://www.figma.com/file/abc123/Project?node-id=1%3A2"
  title="Onboarding prototype"
  aspect="16/9"
  caption="Prototipo navegable. R reinicia."
/>
```

Requiere que el archivo Figma esté en **"Anyone with the link can view"**.
Community files no permiten embed (CloudFront devuelve 403). Para
exploraciones tipográficas o frame stacks usá `<FrameGrid>` con PNG export.

### `<Video>` con `fullBleed` y `demoHref`

```mdx
<Video
  src="./demo.mp4"
  poster="./demo-poster.jpg"
  caption="Drag-and-drop interaction prototyped in Framer"
  fullBleed
  demoHref="https://demo.example.com"
  demoLabel="Try it →"
/>
```

Por defecto: `autoplay`, `muted`, `loop`, `playsInline`. Para clips de 5-10s
sin sonido. El `demoHref` muestra un link "Try it →" al lado del caption.

### `<DemoFrame>` con iframe sandboxed

```mdx
<DemoFrame
  href="https://demo.example.com/workflow"
  title="Workflow composer"
  height="32rem"
  caption="Drag a node onto the canvas to compose a workflow."
/>
```

Renderiza un iframe con header tipo navegador (3 dots, URL chip, "Open ↗").
Sólo funciona si el sitio destino permite framing.
