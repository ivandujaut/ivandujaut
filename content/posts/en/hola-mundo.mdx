## About this blog

I'll document my learning process in software development, English, AI
and other topics that interest me. It's both a professional portfolio
and a personal journal.

## Stack

This site is built with:

- Next.js 15 with App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- next-intl for bilingualism
- Velite for processing MDX

Next posts will be about how I built each piece.
