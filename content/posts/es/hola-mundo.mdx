Bienvenido a mi blog. Este es el primer post que publico acá, principalmente
para verificar que todo el setup funciona correctamente.

  Este post es una prueba de los componentes MDX. Vas a ver varios ejemplos de los bloques que tengo
  disponibles.

## Sobre este blog

Acá voy a documentar mi proceso de aprendizaje en desarrollo de software,
inglés, IA y otros temas que me interesan. Es tanto un portfolio profesional
como una bitácora personal.

<Callout type="insight" title="Por qué un blog">
  Escribir es la mejor forma de internalizar lo que aprendés. Si no podés explicarlo, probablemente
  no lo entendiste.
</Callout>

## Stack

Este sitio está construido con:

- Next.js 15 con App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- next-intl para bilingüismo
- Velite para procesar MDX

## Ejemplo de código

Acá un snippet de cómo se ve un code block con syntax highlighting:

```ts
export function getPosts(locale: "es" | "en") {
  return posts
    .filter((p) => p.locale === locale)
    .filter((p) => process.env.NODE_ENV === "development" || !p.draft)
    .sort((a, b) => +new Date(b.date) - +new Date(a.date));
}
```

Notá el botón de copy que aparece al hacer hover en el code block.
