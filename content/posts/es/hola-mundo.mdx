Bienvenido a mi blog. Este es el primer post que publico acá, principalmente
para verificar que todo el setup funciona correctamente.

## Sobre este blog

Acá voy a documentar mi proceso de aprendizaje en desarrollo de software,
inglés, IA y otros temas que me interesan. Es tanto un portfolio profesional
como una bitácora personal.

## Stack

Este sitio está construido con:

- Next.js 15 con App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- next-intl para bilingüismo
- Velite para procesar MDX

Los próximos posts van a tratar sobre cómo armé cada pieza.
