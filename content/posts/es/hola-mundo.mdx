## Cómo lo armé

<Steps>
  ### Setup inicial
  Arranqué con `create-next-app` y configuré TypeScript, Tailwind y shadcn.

### CI/CD

Sumé GitHub Actions, Husky con lint-staged, y Dependabot para mantener
las deps al día.

### Bilingüismo

Configuré next-intl con detección de idioma y banner de sugerencia.

### Contenido

Velite con schemas Zod para procesar MDX y generar tipos automáticos.

</Steps>

export function getPosts(locale: "es" | "en") {
  return posts
    .filter((p) => p.locale === locale)
    .filter((p) => process.env.NODE_ENV === "development" || !p.draft)
    .sort((a, b) => +new Date(b.date) - +new Date(a.date));
}
